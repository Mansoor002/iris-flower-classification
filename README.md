# Iris Flower Classification and EDA

An exploratory data analysis (EDA) and multi-class classification project using the classic **Iris dataset** to predict flower species based on sepal and petal dimensions.

## Project Files
* **[Iris Multi-Class Flower Classification.ipynb](https://github.com/Mansoor002/iris-flower-classification/blob/main/Iris%20Multi-Class%20Flower%20Classification.ipynb)**: Jupyter Notebook containing the data analysis, visualizations, and code.
* **[Iris.csv](https://github.com/Mansoor002/iris-flower-classification/blob/main/Iris.csv)**: The cleaned dataset containing 150 rows and features like sepal/petal length & width.

## Project Overview
This project explores the Iris dataset to understand feature distributions, correlations, and relationships between various flower parameters. It serves as a foundational machine learning project for multi-class classification problems.

## Dataset Features
The dataset contains 150 samples with the following 4 numerical features and 1 target variable:
1. **SepalLengthCm** (Length of the sepal)
2. **SepalWidthCm** (Width of the sepal)
3. **PetalLengthCm** (Length of the petal)
4. **PetalWidthCm** (Width of the petal)
5. **Species** (Target: *Iris-setosa*, *Iris-versicolor*, *Iris-virginica*)

## Exploratory Data Analysis & Visualizations
* **Species Distribution:** Checked class balance across all three species using a pie chart (balanced dataset with 50 samples per class).
* **Scatter Plot:** Analyzed the relationship between Petal Length and Petal Width.
* **Correlation Heatmap:** Evaluated the correlation matrix across numerical features.

## Technologies Used

* **Pandas & NumPy** (Data manipulation and analysis)
* **Matplotlib & Seaborn** (Data visualization)
